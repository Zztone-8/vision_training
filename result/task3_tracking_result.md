# 任务3 风车目标识别结果说明

对应代码：[src/task3_windmill/main.cpp](../src/task3_windmill/main.cpp)

处理内容：对 `resources/task_3.mp4`、`resources/task_4.mp4` 逐帧做三类识别并叠加标注，
输出两个结果视频（见文末链接）。每帧识别对象：

1. **圆形靶标**（发橙色光的同心圆图案：外圆 + 内圆 + 中心点）；
2. **箭头链**（HUD 中指向靶标的 ">>>>" 雪佛龙图标，并计算 箭头质心→靶标圆点 连线与图像水平轴的夹角）；
3. **字母 "R" 图标**（橙色近方形单孔字形）。

---

## 1 检测方法

### 1.1 圆形靶标检测 `detectCircleTargets()`

流程（颜色 → 形态学 → 拓扑 → 几何 → 同心结构 → 去重）：

1. **HSV 双区间橙色阈值**：H∈[0,30] ∪ [166,180]，S≥80，V≥50。
   V 下限放得较松（50），因为暗场里靶标笔画偏暗偏细，阈值过严会导致圆环断裂。
2. **5×5 闭运算**弥合笔画断点（只在参与轮廓提取的 mask 上闭，径向剖面用原始 mask）。
3. `findContours(RETR_CCOMP)` 后只取**孔洞轮廓**（`hierarchy[i][3] != -1`，即被圆笔画围住的封闭内部区域）。
4. **几何筛选**：
   - 内切圆半径 10 ≤ r ≤ 90 px（远小近大的有效范围）；
   - 圆形度 `4πA/P²` ≥ 0.55；
   - 填充率 `A/(πr²)` ≥ 0.70（孔洞要接近其外接圆）。
5. **同心圆计数** `countConcentricRings()`：从圆心沿半径每 0.5px 取一层圆周，均匀采样 60 点，
   橙色覆盖率 ≥ 30% 的连续半径区间记为一个"环带"，最多扫到 1.25r。
   真靶标（外圆+内圆+中心点）≥ 2 个环带；**只有 1 个环带的单一圆环**
   （风车臂末端装饰圈等）被排除。
6. **NMS 去重**：候选按得分 `圆形度 × 填充率` 降序，质心距离 < 0.8×max(r) 视为同一靶标，只留高分者。

### 1.2 箭头链检测 `detectArrowChain()`

思路：雪佛龙笔画是亮橙色小 glyph（与靶环红 H≈5、黄色臂条 H≈20 色相不同），
检出后做"链"级几何验证，并**要求链的长轴正对某个靶心**，以此排除 "R" 字母、能量块支架等噪声。

1. HSV 阈值 H∈[4,18]，S≥150，V≥130；把该靶标 2.2r 半径内的像素抹掉（去掉靶环与刻度自身）。
2. 连通域过滤：面积 8–3000、宽/高 ≤130；质心到靶心距离须在 **2.3r–7r 环带**内；
   排除 ≤16×16 且填充率 >0.85 的实心小圆点（那是光点不是笔画）。
3. **并查集聚类**：质心间距 <28px 的碎片归为同一条链（雪佛龙本身由多个小 glyph 组成，
   运动模糊后呈"点串"，见调试图 `dbg_chainmask_*.png`）。
4. 每个聚类验证：总点数 ≥20；面积下限（多块 ≥120，单块 ≥250）；`fitLine` 主轴长 L∈[35,160]；
   细长性：垂直厚度 W ≤ 0.45L+8 且 ≤34（单块粘连时另要求最小外接矩形长宽比 ≥2.2）；
   **长轴与"链质心→靶心"向量夹角 ≤28°**；链质心距靶心同样在 2.3r–7r 内。
5. 打分 `得分 = 10×分块数 + 面积/200 − 夹角`，对**该靶标**取分最高的链。
6. 输出角度：箭头质心→靶标圆点连线相对水平轴夹角（数学约定 x 向右、y 向上，逆时针为正）。

### 1.3 字母 R 检测 `detectLetterR()`

与箭头链同色阈值（不抹靶区），连通域满足：宽高 12–40、面积 ≥150、填充率 ≥0.55、
长宽比 0.5–1.8，且**恰好 1 个内孔**（R 的圈）孔面积 ≥5；多个命中时取面积最大者。
命中后白圈圈住并标注坐标，左上角显示 "R Flag: 1"。

## 2 锁定和重选规则

本实现**不跨帧记忆**（无跟踪器状态），"锁定"都发生在单帧内部，帧帧重选：

| 环节 | 规则 |
|---|---|
| 靶标去重 | 同一靶标的内/外缘等多个候选重叠（质心距 < 0.8×max(r)）时，锁定得分（圆形度×填充率）最高者，其余丢弃；下一帧重新评选 |
| 箭头→靶标关联 | 每个靶标独立搜索自己的箭头链，候选聚类中锁定 10×块数+面积/200−夹角 的最大者 |
| 画面主锁定 | 在所有"箭头–靶标"配对中，锁定**箭头质心到靶心距离最小**的一对，用蓝框、蓝线、夹角文字标注；其余配对不画 |
| R 图标 | 满足几何+单孔条件的连通域中锁定面积最大的一个 |
| 跨帧 | 每帧从零重检测、重锁定，无预测/外推，因此锁定对象可在相邻帧间整体切换 |

## 3 已知失败情况

由参数窗口和调参记录（`dbg_chainmask_143/206/246/342/413/501/517/550.png` 为箭头链难点帧调试图）归纳：

1. **暗场/遮挡漏检靶标**：靶标位于画面边缘光照不足、或被风车臂瞬时遮挡时，圆笔画断开、孔洞不封闭，整帧 `targets` 会掉到 0（旧版输出帧 579 即为一例：斜视靶标未被识别，`targets: 0`）。
2. **视角过斜漏检**：靶标大角度倾斜时孔洞轮廓圆形度/填充率跌破 0.55/0.70 阈值。
3. **半径窗口外丢弃**：r<10px（过远）或 r>90px（过近出特写）的目标一律不检。
4. **无帧间锁定的抖动**：临界帧里绿圈/蓝框闪烁、夹角文字跳变；两靶标靠得近或两条箭头链到各自靶心距离接近时，锁定的"箭头–靶标"对会来回切换。
5. **箭头链漏检**：链大部分出画（拟合长 <35px）、与支架笔画粘连（厚度超限或长轴不正对靶心 >28°）、距靶心 <2.3r 或 >7r，都会判无箭头；点串间距超过 28px 时聚类断裂也会导致漏检。
6. **单环误判风险**：装饰圈若与外侧橙色碎片恰好在径向剖面中形成 ≥2 个环带会被误当靶标（环带扫描延伸到 1.25r）；反之真靶标若笔画粘连成一整块，环带数不足 2 也会被排除。
7. **R 图标**：其它"近方形+单孔"字形可能被误报；运动模糊使 R 内孔断裂时漏报（R Flag 闪烁）。
8. **只标注最近一对**：指向其它靶标的箭头即使被正确检出也不会在画面上显示，属设计选择，容易被误认为漏检。
9. **工程限制**：输出目录 `result/task3_windmill/task_3|task_4/` 必须预先存在，否则 `VideoWriter` 打不开直接退出；两视频帧率取属性值，异常时回退 60fps。
