# 2 估计角速度运行公式的四个参数：振幅A、平均⻆速度b、频率参数Ω、相位φ。
*** 采用粗扫 Ω+线性最小二乘的方法 ***
已知：
ω(t) = b+A*sin(Ωt+φ) = b+ A*cos(φ)*sin(Ωt) + A*sin(φ)*cos(Ωt)
设：
c1 = A*cos(φ)
c2 = A*sin(φ)
则：
ω(t) =  b+ c1*sin(Ωt) + c2*cos(Ωt)

固定任意 Ω 后，(b,c1,c2)就是普通线性回归，有解析解；
上式中Ω（频率参数），t是已知时间轴：frame*（每帧间隔1/60秒）；frame从0~1439
解析出（b,c1,c2）之后可以依据公式反推A
A = sqrt{c_1*c_1* + c_2*c2*}, 
φ = atan2(c2, c1)
对Ω 做一维网格搜索（从0.5~5.0，步长0.01），取残差平方和最小的Ω 

计算结果：
| 量 | 估计值 |
|---|---|
| b |  1.35 rad/s |
| A | 0.5499 rad/s |
| Ω | 1.6498 rad/s |
| φ | 0.7 rad |
